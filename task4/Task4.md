# Task IV — Prototype, Facade, Visitor (вариант 9)
 
Создайте систему для управления библиотекой с использованием паттернов Prototype, Facade и Visitor. Prototype будет создавать копии книг, Facade будет предоставлять простой интерфейс для работы с библиотекой, а Visitor будет добавлять новую функциональность для обработки книг.
 
Тут минимальный UI обязателен
 
сервер не обязательно, сторедж может быть в браузере
 
kiss тут допускается
 
но паттерны должны при этом работать и быть хоть сколько-то полезными 
Система управления библиотекой.

## Паттерны
| Паттерн | Роль |
|---------|------|
| Prototype | `clone()` у книг + каталог шаблонов для быстрых копий |
| Facade | `LibraryFacade` — единый API: добавить / взять / вернуть / клонировать / отчёты |
| Visitor | отчёты и штрафы без изменения классов книг |

## Запуск

```bash
cd task4
npm install
npm run dev
```
