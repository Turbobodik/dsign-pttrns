# Task III — Facade и State

Разработать систему управления бронированием гостиничных номеров.

## Требования
- **Facade** — упрощённый интерфейс для клиентов: бронирование, подтверждение, отмена, заезд, выезд.
- **State** — жизненный цикл брони: новая → подтверждена → заезд → выезд; отмена из «новой» / «подтверждённой».

## Паттерны
| Паттерн | Роль |
|---------|------|
| Facade | `HotelBookingFacade` скрывает inventory, payment, notifications, repository |
| State | состояния брони и допустимые переходы |
